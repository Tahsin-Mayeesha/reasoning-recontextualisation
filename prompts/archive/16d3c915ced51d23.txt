
ROLE: Puzzle Surface Transformation Generator

You receive a logic-puzzle unit:
  <context>
  <clues>
  <question> — question text + answer choices (A–E)

Recontextualise it into a new domain while preserving structure.

-----------------------------------
STEP 1 — TARGET DOMAIN

<target_domain>
name:        <short label>
containers:  <what orders items>
items:       <what is arranged>
identifiers: <item names>
</target_domain>

-----------------------------------
STEP 2 — ENTITY MAPPING

<mapping>
container_singular: <orig> -> <targ>
container_plural:   <orig> -> <targ>
item_singular:      <orig> -> <targ>
item_plural:        <orig> -> <targ>
item_identifiers:
  <ORIG_1> -> <TARG_1>
  <ORIG_2> -> <TARG_2>
  ...
</mapping>

Rules:
- 1–1 mapping only
- Use mapping everywhere (context, clues, question, choices)
- No new entities

-----------------------------------
STEP 3 — ADAPT THE FULL UNIT

Rewrite using mapping.

MUST PRESERVE:
- number of items and containers
- structure of clues
- logical relations in each clue
- directionality (pos(A) < pos(B) unchanged)
- fixed positions
- question form
- answer choice structure (A–E)

-----------------------------------
CANONICAL CONSTRAINT FORMS

Each clue preserves its logical form:

- ordering: pos(A) < pos(B)
- adjacency: |pos(A) - pos(B)| = 1
- distance: |pos(A) - pos(B)| = k
- absolute: pos(A) = k
- non_adjacency: |pos(A) - pos(B)| ≠ 1
- all_different: all positions unique
- conditional: if A then B
- disjunctive: A or B
- counting: exactly / at least / at most k satisfy condition
- grouping: same or different group/set

Do not change relation type (e.g., adjacency ↔ distance=2, conditional ↔ disjunction).
Do not merge, split, or reorder any clues under any circumstance.

-----------------------------------
TIER B — FREE:
- wording
- phrasing
- surface structure only

-----------------------------------
STEP 4 — OUTPUT ONLY

<target_domain> ... </target_domain>
<mapping> ... </mapping>
<adapted_puzzle>
  <context> ... </context>
  <clues> ... </clues>
  <question> ... </question>
</adapted_puzzle>
