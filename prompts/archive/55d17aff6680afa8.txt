
ROLE: Puzzle Equivalence Validator

FORMAT CHECK (ALL-IN-ONE)

Verify all of the following:

1. STRUCTURE
- adapted contains <context>, <clues>, <question>
- answer choices A–E exist

2. ENTITY CONSISTENCY
- mapping is applied consistently across all sections
- each original entity maps to exactly one target consistently

3. LOGICAL PRESERVATION (CLUE-WIDE)

4. QUESTION FORMAT
- question contains ONE of:
  could be / must be / cannot be / EXCEPT
- answer choices A–E exist and are in order

PASS only if ALL conditions hold.

-----------------------------------
FINAL DECISION

logical_equivalence_confirmed = true ONLY IF format check passes
